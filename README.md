# 自由市场摊位扫描器

Windows GUI 工具：从 MapleStory 自由市场入口依次进入 **1–20号洞**，识别当前屏幕可见的两类摊位（对话框摊位、房屋摊位），逐个打开并退出；每个洞按频道顺序扫描。

## 支持范围

| 项目 | 当前支持 |
| --- | --- |
| 游戏客户端 | Windows 窗口模式 |
| 客户端内容区域 | **固定 1920×1080** 像素 |
| 起点 | 自由市场入口或 1–20 号洞，任意频道 |
| 普通扫描流程 | 自动识别当前洞；从当前洞/频道向后扫描至 20 号洞，每洞优先回到 CH.1 后离洞；CH.1 不可用时依次尝试后续频道；回到 1 号洞后自动开始下一轮，直至手动停止 |
| 摊位类型 | 对话框招牌、粉色/黄色/米色房屋招牌 |
| 停止方式 | GUI 的“停止”、`F9`、或将鼠标移至主屏幕左上角 |

客户端内容区域不是包含标题栏和窗口边框的外部窗口尺寸。若不是 1920×1080，程序会停止并把实际尺寸写入日志，避免错误点击。

## 按键

程序发送的是 Windows `SendInput` 扫描码，使用以下游戏默认键位：

| 行为 | 键位 |
| --- | --- |
| 向左 | `←` |
| 向右 | `→` |
| 向上 | `↑` |
| 向下 | `↓` |
| 跳跃 | `Space` |
| 关闭商店 / 打开游戏菜单 | `Esc` |
| 紧急停止 | `F9` |

请在游戏中保留这些默认按键；如果改过键位，先恢复为上表设置再使用。

## 使用方法

1. 将游戏设为窗口模式，并将客户端内容区域设为 **1920×1080**。
2. 进入自由市场入口或任意 1–20 号洞，关闭商店和菜单。可以从任意频道开始，例如 CH.7。
3. 运行 `market_screen_scanner\dist\MarketScreenScanner.exe`，接受 Windows 管理员权限提示。
4. 在“游戏窗口”列表选择 MapleStory；没有显示时点击“刷新列表”。
5. 点击“开始扫描”。程序会建立本次位置连接，依次进入 1–20 号洞；每洞扫描当前频道至 CH.40，确认回到 CH.1 后离洞。每轮完成后会回到 1 号洞 CH.1 并自动开始下一轮；“暂停”会保留当前洞、频道和进度，“继续”会从该处恢复。使用“停止”、`F9` 或鼠标移至左上角结束。
6. GUI 会显示当前频道、累计已点击店铺，以及当前店铺的客户端内 `X/Y` 点击点。

GUI 可以自由缩放。开始、扫描、切换频道和结束都不会再修改它的大小或位置。

## 动作节奏

鼠标移动会根据距离使用不同的速度、缓动、中间路径和少量末端修正。店铺之间使用一次会话内保持一致但不固定的节奏：短操作会成组出现，期间可能只是停顿，也可能有少量左右移动；跳跃是低概率的偶发动作，并会不定期插入更长的观察停顿。每个频道切换成功后，也会先执行很短的移动序列再开始识别。

## 频道确认与日志

EXE 随附官方 WinDivert 的已签名驱动，并以 `SNIFF | RECV_ONLY` 模式被动读取频道状态；不会修改、阻断、注入或记录游戏数据包。如果抓包不可用，程序使用频道菜单的可见选中状态作为确认方式。

当前运行的截图、识别结果、频道切换事件、失败原因和 `scanner.log` 位于：

```text
%LOCALAPPDATA%\ClassworldFMBot\screen_scanner\<运行时间>\
```

点击新的“开始扫描”会清空上一轮的运行目录；暂停后点击“继续”保留当前目录与进度。`scanner.log` 只记录启动、失败和恢复信息，逐店结果写在 `visits.jsonl`。

其中 `full_scan.jsonl` 记录进出洞与入口层传送；`channels.jsonl` 记录频道读取、切换结果、店铺已关闭验证与每次频道进入后的动作；各 `room_XX_ch_YY` 目录中的 `visits.jsonl` 记录店铺坐标、打开/关闭结果和店铺间动作。

## 构建

在仓库根目录使用 Windows Python 环境安装依赖并运行构建脚本。脚本会从官方 WinDivert 发布页下载、校验并打包所需 DLL 和驱动：

```powershell
py -m pip install -r market_screen_scanner\requirements.txt
.\market_screen_scanner\build.ps1
```

正式单文件输出固定为：

```text
market_screen_scanner\dist\MarketScreenScanner.exe
```

## 房间路线与位置反馈

扫描期间会启动第二个只读 WinDivert 采集器。它只在本机写入派生状态
`%LOCALAPPDATA%\ClassworldFMBot\player_position.json`：地图、频道、世界 `X/Y`、foothold 和连续位置序号；不会保存或发送游戏报文。

房间间移动使用该位置反馈。到门口时先从一侧走过门口一小段，再反向走回小距离并按 `↑`，而不是在门正中固定停下。坐标不可用时才使用复位路线：`↓ + Space` 至少三次、走到右端、再走回左端。勇士部落入口还需要已记录的梯子坐标，才会向上离开。

### 地图进出洞测试（运行时）

勾选 GUI 的 **“地图进出洞测试（不扫描、不保存路线）”** 后，工具只观察当前这一次的地图加载：

1. 角色在 FM 入口，关闭商店和菜单后点击“开始地图测试”。
2. 手动切换到任意频道一次，等待加载完成。这个新连接让只读解码器取得本次会话的密钥。
3. 手动进入 1 号洞，在洞内走几步，再离开回入口。
4. 测试在第三次地图加载后自动完成，GUI 显示洞内的起点和离开前终点坐标。

它不点摊位、不发送网络数据，也不会写 `free_market_route.json`。本次的地图 epoch、已解出的地图 ID（若该客户端包格式提供）、起点和终点只写入本次运行目录的 `scanner.log`；位置采集状态位于 `%LOCALAPPDATA%\ClassworldFMBot\player_position_status.json`。地图 ID 解出后，下一步才可从本机 `Map.wz` 读取对应的 portal、梯子和平台结构。
